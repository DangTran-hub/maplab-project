# Mobile application

This directory reserves space for the React Native reporter app. It is not yet
initialized and has no install, development, or build commands.

Initialize the mobile project here when choosing its React Native tooling.
Organize application code under `src/` using `screens/`, `components/`,
`navigation/`, and `services/`; keep images and other static files in `assets/`.

The app will capture issue details, photos, and coordinates, submit reports, and
display their status through the shared backend API. Database access belongs to
the backend. See `../docs/PRODUCT.md` for scope.
